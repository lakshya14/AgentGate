# Git Push Approval Rule

You must **NEVER** run `git push` or deploy code to external remote repositories without explicitly asking for and receiving the USER's approval first. 

Even if you believe the change is trivial or part of an ongoing task, you must always stop, summarize the changes you are about to push, and wait for the user to explicitly say "yes" or "go ahead" before executing the push command.
